# NEURON AI

Dein strategischer Sparringspartner mit News-Radar – ehrliche Auswertungen statt blinder Bestätigung.

**App öffnen:** über GitHub Pages (Settings → Pages → main branch → root).
Auf dem Handy: Seite öffnen → „Zum Home-Bildschirm" (iPhone/Safari) bzw. „App installieren" (Android/Chrome).

Der Anthropic-API-Key wird nur lokal im Browser gespeichert (⚙ Einstellungen).
